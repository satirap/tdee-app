# Add food to My Food

เมื่อผู้ใช้บอกชื่ออาหาร (และปริมาณ/หน่วยถ้ามี) ในแชต ให้ประมาณโภชนาการแล้วเขียนลง
`shared/foods.foods{}` ตรง ๆ ผ่าน REST แบบ field-level (ไม่กระทบอาหารเดิม).

## 0. ทำได้ที่ไหน
- `CLAUDE.local.md` มีอยู่ (เครื่องผู้ใช้) → ทำได้ (ต้องใช้ PIN จากไฟล์นั้น).
- ไม่มี (cloud session) → **หยุด เขียนข้อมูลไม่ได้** ให้ผู้ใช้ไปเพิ่มจากเครื่องตัวเอง.

## 1. ประมาณค่า (ต่อ 1 serving)
สำหรับอาหารแต่ละอย่าง กำหนด:
- `name` ชื่อตามที่ผู้ใช้พิมพ์ (ปรับให้อ่านง่าย ไม่ต้องเปลี่ยนความหมาย)
- `unit` + `amt` หน่วยเสิร์ฟ เช่น `unit:"ชิ้น", amt:1` → serving = "1 ชิ้น" (ดูของเดิม: แก้ว/ชิ้น/ขวด/จาน/ทัพพี…)
- `g` กรัมต่อ 1 serving (ถ้าพอประมาณได้ ใส่; ไม่รู้จริง ๆ ใส่ null)
- `p,c,f` กรัม ต่อ 1 serving; `kcal` = kcal ต่อ 1 serving
- ยึดหลัก `kcal ≈ 4·P + 4·C + 9·F` (สคริปต์เตือนถ้าต่างเกิน 15%)
- เช็กก่อนว่ามีใน `STD_FOODS` (foods-th.js) หรือ My Food อยู่แล้วไหม (กันซ้ำ — grep ชื่อในไฟล์ backup ล่าสุด หรือดูข้อความผู้ใช้); ถ้ามีแล้วบอกผู้ใช้ ไม่ต้องเพิ่มซ้ำ

บอกผู้ใช้สั้น ๆ ว่าค่าที่ประมาณมาจากไหน/มั่นใจแค่ไหน แล้ว **ให้ผู้ใช้ยืนยันตัวเลขก่อนเขียน**
(ตัวเลขเป็นค่าประมาณ ผู้ใช้อาจอยากปรับ). ถ้าผู้ใช้สั่ง "เพิ่มเลย" พร้อมค่าชัด → เขียนได้เลย.

## 2. เขียน (field-level + backup + verify ในตัว)
อ่าน PIN จาก `CLAUDE.local.md` แล้วรัน (ส่งได้หลายรายการใน array เดียว):

```
python3 -I .claude/skills/add-food/add_food.py --pin <PIN> --json '[
  {"name":"อกไก่ย่าง","p":27,"c":0,"f":3,"kcal":138,"unit":"ชิ้น","amt":1,"g":100}
]'
```

สคริปต์จะ: backup ก่อน → PATCH `updateMask=foods.<id>` ทีละรายการ (id สุ่ม 7 ตัวแบบ `uid()` ของแอป)
→ backup หลัง → ตรวจว่า **ของเดิมไม่ถูกแก้/ไม่หาย** และจำนวนเพิ่มพอดี → พิมพ์ `RESULT: OK ✅` + id ที่เพิ่ม.
ลองก่อนด้วย `--dry-run` ได้. ชื่อซ้ำจะถูกข้าม เว้นแต่ใส่ `--force`.

- ห้ามใส่ PIN ลงไฟล์ skill/commit (เป็นความลับใน CLAUDE.local.md) — ส่งผ่าน `--pin` ทุกครั้ง.
- **ห้ามใช้ `setDoc`/เขียนทับทั้งเอกสาร** หรือแตะ `uses`/`meals`/`hidden`/`cats` — skill นี้เพิ่ม `foods.<id>` เท่านั้น.

## 3. รายงาน
บอกผู้ใช้: เพิ่มอะไรไปบ้าง (ชื่อ + P/C/F/kcal ต่อ serving + id), จำนวน My Food ก่อน→หลัง, และผล `OK ✅`.
ถ้าผล `FAIL` ให้หยุดและให้ผู้ใช้ดู backup ที่สคริปต์พิมพ์ path ไว้ (อย่าลองเขียนซ้ำมั่ว).

## โครงสร้าง 1 รายการใน `foods.<id>` (อ้างอิง)
`{ name, p, c, f, kcal, amt, unit, serving:"<amt> <unit>", g|null, units:[], barcode:null, created:<ms> }`
— ค่า p/c/f/kcal เป็น **ต่อ 1 serving**; แอปอ่านผ่าน `getFood(id)` และคูณ qty เองตอนบันทึกมื้อ.
